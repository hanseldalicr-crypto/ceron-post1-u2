# ceron-post1-u2
Laboratorio — Página Semántica y Formulario de Registro con HTML5

Paso 6: Logros y certificaciones — decisión de diseño semántico
    Se decidió estructurar cada certificación utilizando elementos <article> independientes, porque son unidades de información completas y tienen sentido por si solas afuera del sitio. 
    Esta decisión permite que el contenido sea redistribuible y fácil de reutilizar sin perder contexto.

Paso 7: Multimedia y preguntas frecuentes — decisión de formato
    Se optó por un elemento de audio con formatos MP3 y OGG acompañado de su transcripción textual, debido a que permite una carga más ligera y directa en el sitio web sin descuidar la accesibilidad. Esta estructura asegura que la información sea totalmente accesible para cualquier usuario, cumpliendo con los estándares de perceptibilidad.
